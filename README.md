# Food Basket

Исходники парсеров размещаются отдельно в каталоге `parsers/`.

- [Яндекс Лавка](parsers/yandex_lavka/README.md) — поиск товаров, расчёт корзины, сбор каталогов по складам и экспорт данных.

Для установки и запуска парсера Лавки перейдите в `parsers/yandex_lavka/` и следуйте его README.

- [Ozon Fresh](parsers/ozon_fresh/README.md) — сбор каталога по адресам, цены, характеристики и выгрузка данных; отчёт на КП2 за 10 ноября 2026 года.

- [ВкусВилл](parsers/vkusvill/README.md) — асинхронный сбор каталога по H3-зонам: цены, наличие с остатком, описание, состав и КБЖУ; отчёт на КП2 за 10 ноября 2026 года.

Для установки и запуска парсера ВкусВилла перейдите в `parsers/vkusvill/` и следуйте его README.
