# Парсер ВкусВилла (асинхронный)

Собирает по зонам доставки (`hexagons.csv`) товары ВкусВилла: название, цену, наличие с остатком,
описание, состав, КБЖУ, страну, срок годности. Результат — CSV по шаблону `template.csv`
(лишние поля — в колонке `extra`).

## Запуск

```bash
pip install -r requirements.txt
python vkusvill_async.py --limit 10                      # первые 10 зон, весь каталог
python vkusvill_async.py --limit 10 --food-only          # только продуктовые разделы
python vkusvill_async.py --okrug ЦАО САО                 # зоны выбранных округов
python vkusvill_async.py --sections myaso-ptitsa syry    # только выбранные разделы
```

Результат: `vkusvill_<дата>_khramova.csv` (или `--out <файл>`). Перезапуск продолжает с места
остановки: готовые зоны и скачанные карточки товаров (`details_cache.jsonl`) не перекачиваются.

## Как работает

1. **Адрес зоны.** Для каждой зоны: `GET /goods/` (cookies + `sessid`) →
   `POST /ajax/address_way/get_Coords.php` (координаты дома зоны) →
   `POST /ajax/address_way/service_apply.php`. После этого каталог показывает только то,
   что доставляется в зону, с остатком («В наличии 39 шт»).
2. **Склад.** ID склада сайт не показывает, поэтому склад узнаётся по «отпечатку» остатков
   на двух страницах каталога. Зоны того же склада получают каталог копированием.
3. **Каталог.** `GET /goods/<раздел>/?PAGEN_1=N` с `X-Requested-With: XMLHttpRequest`
   (только карточки); разбор через lxml.
4. **Карточка товара.** `GET /goods/<slug>-<id>/` — JSON-LD `Product` + блоки описания:
   описание, состав, КБЖУ (два формата записи), страна, срок годности. Не зависит от зоны,
   качается один раз на товар и кэшируется.

Асинхронность: `asyncio` + `aiohttp`. Сайт на Битриксе обрабатывает запросы одной сессии
по очереди, поэтому параллельность — через пул отдельных сессий.

## Ограничения сайта и как они учтены

| Ограничение | Что делает парсер | Параметр |
|---|---|---|
| Защита QRATOR банит IP при > ~4 запросов/с | общий потолок скорости | `--rps 4` |
| Смену адреса сайт разрешает ~15 раз подряд, потом «Сессия истекла» | смена адреса не чаще раза в 35 с; после отказа пауза 1→2→4→8→10 мин | `--addr-gap 35`, `--max-refusals 6` |
| 429 / 403 / сброс соединения | общая пауза 5 с … 5 мин, затем остановка | — |
| Сетевые сбои, 5xx | до 5 повторов с нарастающей задержкой | — |

Время и стоимость доставки не собираются; `store_id` пуст, вместо него `store_fp` в `extra`.
