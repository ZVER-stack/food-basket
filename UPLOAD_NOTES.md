# Исходники парсера Яндекс Лавки

В этом каталоге находятся адаптер корзины, сборщики каталогов, сопоставление зон со складами, экспорт, тесты и ранее полученное соответствие H3-зон складам.

Установка: Python 3.10+, затем `python -m pip install -e .`.
Проверка без сети: `python -m unittest discover -s tests -v`.
Команды запуска и структура данных описаны в README.md.

Папки с текущей базой, сырыми ответами, логами и PID сюда не включены. Они содержат результаты запусков, а не исходный код. Сборщик соблюдает паузы между запросами и прекращает работу при ограничениях сервиса.
