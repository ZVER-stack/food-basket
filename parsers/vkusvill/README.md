# Парсер ВкусВилла — статус на КП2

Дата отчёта: **10 ноября 2026 года**. Числа относятся к сохранённым выгрузкам 4–5 ноября, а не к завершённому сбору.

- Реализован асинхронный сбор каталога (`asyncio` + `aiohttp`) с привязкой цен и наличия к H3-зонам. Для каждой зоны выбирается адрес доставки, затем обходится каталог с ценой и остатком этой зоны. Результат — CSV по шаблону `template.csv`. Предусмотрено продолжение после остановки: готовые зоны и скачанные карточки не перекачиваются.
- **Полный каталог (4–5 ноября):** обработано 9 зон, получено **133 753 записи «товар — зона»** и **16 777 уникальных ID товаров**, найдено 6 складов. Одна зона записана без товаров и требует перепроверки.
- **Продуктовые разделы (5 ноября):** бакалея, мясо, молочка, сладкое, рыба, овощи. Обработано **16 зон**, получено **63 713 записей** и **3 983 уникальных ID**, найдено 12 складов. Остатки по зонам различаются (у 2 881 из ~3 980 общих товаров), цены совпадают.
- **Карточки товаров:** в кэше 17 049 карточек с описанием, составом, КБЖУ, страной и сроком годности. Этого достаточно для всего каталога.
- **Заполненность полей (продуктовый проход):** название, цена, наличие, описание, состав, страна — 100%; остаток — 93%; ккал — 89%, белки — 86%, жиры — 84%, углеводы — 75%. Пропуски КБЖУ — товары, у которых на сайте эти данные не указаны; значения не подставляются.
- **Проверка:** отдельного набора автотестов нет. Разбор карточек и страниц товаров проверен на реальных фрагментах HTML. Асинхронная часть (сессии, повторы, паузы, кэш, продолжение) прогнана на имитации сайта с отказами. Живые проходы: 1, 5 и 16 зон.
- **Ограничение результата:** данные сняты 4–5 ноября. Полный проход по выбранным 10 зонам ещё не запускался. Время и стоимость доставки не собираются.

## Запуск

```bash
pip install -r requirements.txt

python vkusvill_async.py --limit 10                       # первые 10 зон из hexagons.csv, весь каталог
python vkusvill_async.py --limit 10 --food-only           # только продуктовые разделы
python vkusvill_async.py --okrug ЦАО САО                  # зоны выбранных округов
python vkusvill_async.py --sections myaso-ptitsa syry     # только выбранные разделы каталога
python vkusvill_async.py --out vkusvill_2026-11-10_khramova.csv   # имя выходного файла
```

На macOS длинный прогон лучше запускать через `caffeinate -i python vkusvill_async.py …`, чтобы компьютер не уснул.

Результат: `vkusvill_<дата>_khramova.csv` в папке скрипта. Повторный запуск той же командой пропускает зоны, уже записанные в CSV; описания товаров берутся из `details_cache.jsonl`.

Основные параметры:

| Параметр | По умолчанию | Что задаёт |
|---|---|---|
| `--rps` | 4 | общий потолок запросов в секунду |
| `--zones` | 4 | сколько зон обрабатывается одновременно |
| `--pages` | 1 | сессий на зону (каждая — отдельная смена адреса) |
| `--details` | 4 | сессий для загрузки карточек товаров |
| `--addr-gap` | 35 | минимум секунд между сменами адреса |
| `--max-refusals` | 6 | сколько отказов «Сессия истекла» подряд терпеть; `1000` — ждать, пробуя раз в 10 минут |
| `--no-stores` | — | не определять склад по остаткам, обходить каталог в каждой зоне |

## Как работает

1. **Адрес зоны.** `GET /goods/` (cookies и токен `sessid`) → `POST /ajax/address_way/get_Coords.php` с координатами дома зоны (`address_lat`, `address_lon`) → `POST /ajax/address_way/service_apply.php`. После этого каталог показывает только то, что доставляется в зону, с остатком («В наличии 39 шт»). Если сайт сообщает, что доставки нет, в CSV пишется пустая строка зоны.
2. **Склад.** ID склада сайт не показывает, поэтому склад определяется по «отпечатку»: пары «товар — остаток» на первых страницах двух разделов. Совпадение ≥ 80% — тот же склад, и каталог копируется без повторного обхода.
3. **Каталог.** `GET /goods/<раздел>/?PAGEN_1=N` с заголовком `X-Requested-With: XMLHttpRequest` (сайт отдаёт только карточки). Разбор через lxml: ID, название, фасовка, текущая и старая цена, остаток, категория, бейджи, акция, рейтинг, картинка, ссылка. Подборки-дубли (`set-*`, «Хиты» и т. п.) пропускаются.
4. **Карточка товара.** `GET /goods/<slug>-<id>/`: JSON-LD `Product` (описание, бренд, рейтинг, отзывы, состав, срок годности, хранение, КБЖУ) и блоки описания (страна, изготовитель, аллергены). КБЖУ встречается в двух форматах — оба разбираются. Карточка не зависит от зоны, скачивается один раз и сохраняется в `details_cache.jsonl`.
5. **Запись.** Поля карточки каталога объединяются с описанием; всё, чему нет колонки в шаблоне (`store_fp`, раздел, аллергены и т. п.), уходит в JSON-колонку `extra`. Зона дописывается в CSV сразу после завершения.

Сайт на Битриксе обрабатывает запросы одной PHP-сессии строго по очереди, поэтому параллельность достигается пулом отдельных сессий.

## Ограничения сайта

| Ограничение | Как учтено |
|---|---|
| Защита QRATOR блокирует IP при частоте выше ~4 запросов/с (полная блокировка наблюдалась 4 ноября) | общий лимит `--rps 4` |
| Смену адреса сайт разрешает примерно 15 раз подряд, затем отвечает «Сессия истекла, обновите страницу» | смена адреса не чаще раза в 35 с; после отказа пауза 1 → 2 → 4 → 8 → 10 мин; после серии отказов новые зоны не начинаются, начатые дописываются |
| HTTP 429 / 403 / сброс соединения | общая пауза от 5 с до 5 мин, затем остановка |
| Сетевые сбои, 5xx, таймауты | до 5 повторов с нарастающей задержкой |

Обход защит не реализуется. Из-за лимита на смену адреса полный проход по всем 201 зоне с одного IP занимает несколько часов: зоны обрабатываются волнами примерно по 15. Для 10 зон лимит не достигается.
