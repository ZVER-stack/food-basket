## Реальный образец

`sample_partial_2026-10-21.csv` содержит **неполный** ассортимент для зоны `8711aa632ffffff`, адрес доставки — Москва, Бакунинская улица, 60/2. Данные получены анонимно в Firefox 158.0.1 из публичного web-клиента Самоката 2.86.1. У каждой строки сохранено фактическое время записи ответа по Москве.

Собраны готовая еда, овощи и фрукты, молочное, хлеб, мясо/рыба и часть морозилки. Остальные пищевые разделы не завершены. В `extra` стоят `sample_partial: true` и `complete_zone: false`. Это **образец формата и реальных данных**, его нельзя считать полным ассортиментом зоны или контрольной точкой основного прохода.

`verification.json` содержит машинный отчёт. В `captured_public_responses/` лежат 34 публичных ответа каталога с параметрами и временем запроса. Заголовков, cookie и токенов там нет. `tests/fixtures/tea_2026-10-21.json` — отдельная реальная карточка товара для регрессионного теста.

## Воспроизвести проверки без запросов к Самокату

Из корня распакованного проекта:

```powershell
py -m unittest discover -s tests -v
py verification/replay_check.py
py -m samokat validate verification/sample_partial_2026-10-21.csv
```

В офлайн-проверке набор разделов намеренно ограничен пятью полностью записанными деревьями. Это не доказательство полноты всей зоны и не повторный сетевой сбор.
