# Парсер Самоката для сравнения продуктовой корзины в Москве

Python 3.11+ и **Firefox**. Парсер использует публичную витрину [Самоката](https://samokat.ru/) в новом временном профиле браузера. Личный аккаунт не нужен. Файлы из исходной папки не изменяются.

По вашему уточнению собираются **только продукты питания**, включая детское питание. Косметика, одежда, товары для дома и животных исключены. Список основных пищевых разделов задан в `FOOD_SECTIONS` в `samokat/catalog.py`; смешанные промо-разделы не используются для определения охвата.

В `data/` включены ваши 201 зона, карта, шаблон на 37 колонок и исходная инструкция. Входные координаты — **`address_lat` / `address_lon` дома**, а не центр гексагона. Это соответствует варианту работы с координатами из задания.

## Установка в Windows

Распакуйте архив и откройте PowerShell в папке с этим README:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Firefox должен быть установлен. Selenium Manager при первом запуске сам подберёт и загрузит geckodriver. Если загрузка драйвера недоступна, установите его отдельно из [официальных релизов Mozilla](https://github.com/mozilla/geckodriver/releases) и укажите `--geckodriver`.

Активировать окружение и менять ExecutionPolicy PowerShell не требуется. На macOS/Linux используйте `python3` вместо `py`, а затем `.venv/bin/python` вместо `.\.venv\Scripts\python.exe`.

## Сначала проверить одну зону

```powershell
.\.venv\Scripts\python.exe -m samokat zones --limit 3
.\.venv\Scripts\python.exe -m samokat probe
```

`probe` открывает Firefox, определяет витрину для первого адреса и получает **одну страницу одной непустой категории**. В `results/probe/` появятся `sample_partial.csv`, `report.json` и журнал. Это проверка подключения и формата, **не полный каталог зоны**. В `report.json` всегда стоит `complete_catalog: false`. Файл пробы не используется при продолжении основного прохода.

На старте сайт может сам кратковременно перенаправить браузер на Sber ID для проверки гостевой сессии. Парсер ждёт возврата, не заполняет формы и не входит в аккаунт. Авторизованную сессию он отклоняет.

## Отладочный проход по трём зонам

```powershell
.\.venv\Scripts\python.exe -m samokat run --limit 3 --surname ivanov
```

Замените `ivanov` на свою фамилию. По умолчанию используется `students`. Результат:

```text
results/samokat_YYYY-MM-DD_ivanov.csv
results/samokat_YYYY-MM-DD_ivanov.sqlite3
results/samokat_YYYY-MM-DD_ivanov.log
```

Дата имени файла и `parsed_at` — московские. CSV — UTF-8, запятая, точка в числах, ровно 37 колонок из `template.csv`.

После проверки — весь набор:

```powershell
.\.venv\Scripts\python.exe -m samokat run --surname ivanov
```

Если запустить в ту же дату с той же фамилией, три готовые зоны будут пропущены. Для продолжения на другой день явно укажите **тот же файл**:

```powershell
.\.venv\Scripts\python.exe -m samokat run --output results/samokat_2026-10-21_ivanov.csv
```

Новый проход с повторным сбором цен запускайте с новым `--output`. Не удаляйте SQLite при сохранении CSV: база хранит контрольные точки.

## Разделить работу с командой

```powershell
.\.venv\Scripts\python.exe -m samokat run --okrug ЦАО САО --surname ivanov
.\.venv\Scripts\python.exe -m samokat run --h3 8711aa632ffffff --output results/samokat_one_zone.csv
```

`--limit N` выбирает первые N зон **после фильтра**, затем из них пропускаются уже завершённые. Фильтры можно расширять при продолжении в ту же базу. Для разных участников используйте разные имена файлов.

## Какие данные собираются

- Склад определяется по координатам **каждого адреса**. Приоритет типов витрины — `MINIMARKET`, затем `SUPERMARKET`, как в web-клиенте сайта.
- Из общего списка выбираются основные пищевые разделы и детское питание. Их деревья раскрываются последовательно; заполненные товарные списки загружаются целиком, а при `hasNextPage=true` дочитываются все страницы. Навигационные плитки без ассортимента раскрываются отдельно, даже если у них `hasNextPage=false`. Товар, встречающийся в нескольких категориях, сохраняется один раз на зону; все найденные пути остаются в `extra.categories`.
- Сохраняются ID, название, граммовка `specification`, текущая и обычная цена, наличие, категория, фото, ссылка, акции и доступные характеристики. Если `specification` пуст, фасовка извлекается буквально из конца названия, например `25 шт.`, `100 г`, `6 шт × 100 г`; источник указан в `extra.amount_source`. Количество не подставляется догадкой. Если обязательное поле отсутствует, зона не завершается.
- Цены `prices.current` / `prices.old` API переводятся **из копеек в рубли**, без ошибок двоичного округления. Если старой цены нет, `price_regular = price`.
- `quantity` используется для признака наличия, но не выдаётся за точный физический остаток склада. Исходное значение сохраняется в `extra.raw_product.quantity`.
- Условия доставки и минимальный заказ запрашиваются заново по каждому адресу. Текстовые обещания ETA не превращаются в число догадкой; числовой SLA учитывает минуты/часы.
- Не подтверждённая отдельным полем стоимость доставки остаётся пустой. Условные цены `amazing` и `promoXY` сохраняются в исходных полях, не подставляются автоматически в `price_card`.
- Все исходные поля товара, включая неизвестные, остаются в `extra.raw_product`; исходные условия доставки — в `extra.raw_showcase`, `raw_settings`, `raw_delivery`.

Внутри пищевых разделов встречаются принадлежности для готовки. Подкатегории вроде «Фольга» и «Пакеты для запекания» исключаются отдельно; их правила доступны в `NON_FOOD_CATEGORIES` и `is_non_food_product` в `samokat/catalog.py`.

Для подробных карточек, состава, производителя и КБЖУ, которые могут отсутствовать в списке:

```powershell
.\.venv\Scripts\python.exe -m samokat run --limit 3 --details --output results/samokat_details.csv
```

`--details` делает дополнительный запрос на каждый уникальный товар склада и может значительно увеличить время работы. Этот режим требует отдельного файла, если предыдущая база создана без подробных карточек.

## Кэш, скорость и ограничения

Каталог повторно используется только при совпадении **`store_id` и `showcase_id`** в течение 15 минут. Если `store_id` не опубликован, кэш отключён. `--cache-ttl 0` полностью отключает кэш. При повторном использовании `parsed_at` сохраняет фактическое время получения товара, а `extra.zone_checked_at` — время проверки нового адреса; в `extra.catalog_reused` ставится `true`.

Запросы к API витрины выполняются последовательно. **По умолчанию пауза 3 секунды**: она увеличена после 403 в пробном сборе с паузой 1,1 секунды. `--interval` позволяет задать другой интервал, но не меньше секунды. Ограничитель работает также на автоматических запросах web-клиента к тому же API. Статические ресурсы страницы, автоматические CORS-preflight и сторонняя телеметрия загружаются самим Firefox в обычном режиме.

При HTTP 403, 429 или видимой капче сбор останавливается. Автоматического повтора после блокировки, прокси-ротации, подмены браузера или решения капчи нет. При следующем ручном запуске увеличьте паузу, например `--interval 5`. Неустранимые ошибки сети, авторизации, 5xx, неизвестная схема, незавершённая пагинация и пустой каталог прерывают проход, сохраняя готовые зоны.

Временные сетевые ошибки и HTTP 500/502/503/504 повторяются не более двух раз с дополнительными паузами 2 и 4 секунды. Если они не исчезли, проход прерывается. Гостевую сессию поддерживает штатный клиент сайта; авторизация в личном аккаунте для этого не выполняется.

**Отсутствие доставки** записывается строкой с тремя полями только после успешного `/showcases/list`, вернувшего пустой список. Закрытый склад или временная приостановка приёма заказов не подменяются отсутствием покрытия.

Время полного прохода зависит от числа складов, категорий, товаров и состояния сайта. Уложиться в два часа без подробных карточек — ориентир задания, а не гарантия. При наблюдаемом большом каталоге сначала оцените время прохода по 3–5 зонам.

## Надёжность и проверка

Каждая полностью загруженная зона сохраняется одной транзакцией в SQLite, после чего её строки дописываются в CSV и сбрасываются на диск. Это позволяет не переписывать весь растущий файл 201 раз. При запуске CSV атомарно восстанавливается из SQLite, поэтому оборванная запись не оставит дублей или повреждённых строк после продолжения. При аварии во время сетевого сбора текущая зона будет собрана заново. Если CSV открыт в Excel и запись невозможна, закройте его и повторите команду — файл восстановится из базы.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m samokat validate results/samokat_2026-10-21_ivanov.csv
```

Валидатор проверяет формат, обязательные поля, известные зоны и дубли. Полноту ассортимента по одному CSV установить нельзя; для неё нужен журнал завершённого прохода.

Укажите путь к браузеру при необходимости:

```powershell
.\.venv\Scripts\python.exe -m samokat probe --firefox "C:\Program Files\Mozilla Firefox\firefox.exe"
```

Версия Firefox из Microsoft Store автоматически обнаруживается в Windows, если стандартная установка отсутствует. Для диагностики есть `--verbose`; журналы не содержат токены, cookie и заголовки авторизации.

Для воспроизводимой отладки можно добавить `--capture-dir work/public_responses`. Сохраняются JSON только тех публичных ответов каталога, которые запросил парсер, с временем и параметрами запроса. Служебные ответы авторизации и заголовки не сохраняются.

## Как устроен код

`samokat/firefox.py` запускает Firefox и контролирует API-запросы через WebDriver BiDi. `samokat/bridge.js` вызывает штатный HTTP-клиент публичного сайта внутри его гостевой сессии; учётные данные не экспортируются в Python. `samokat/catalog.py` реализует `get_catalog(address, lat, lon)`, покрытие зон, пагинацию и кэш. `samokat/core.py` отвечает за формат, преобразование цен и сохранение.

Использованные маршруты определены по публичному клиентскому коду Самоката версии **2.86.1**. Сайт не предоставляет стабильного официального API для этой задачи: при изменении модулей/схемы парсер останавливается, после чего потребуется обновить адаптер. Контрольные точки не превращают ранее собранные цены в текущие — для нового временного среза нужен новый файл.

## Результаты проверки в этом комплекте

Смотрите `verification/README.md`. В комплект включён реальный **неполный образец из 1504 товаров одной зоны**, полученный через Firefox 21 октября 2026 года. Самокат вернул 403 при дальнейшем сборе, и запросы были остановлены. Полный проход по трём пробным зонам и по 201 зоне не завершён; неполный образец не помечен завершённой зоной и не используется как контрольная база основного прохода.

Исходные зоны и адреса предоставлены в задании; атрибуция OpenStreetMap и лицензия ODbL сохранены в `data/README_task.md` и `data/map.html`.
