# Самокат — версия с восстановлением

Python 3.11+, Firefox. Формат CSV (37 колонок) и 201 зона сохранены. При обновлении не заменяются .venv и results.

## Исправление смены контекста страницы (22 октября)

После FETCH_ERROR сайт может перезагрузить документ или сменить Redux store.
Раньше исчезновение служебного JS завершало сбор сообщением «Контекст сайта изменился».
Теперь парсер ожидает готовность гостевой страницы и повторно устанавливает адаптер.
На один запрос остаётся не более трёх попыток всего (включая сетевые повторы и восстановление контекста).
Восстановление ограничено 60 секундами за попытку и выполняется только на samokat.ru.
Неизвестная версия клиента, вход в аккаунт, капча и 403/429 по-прежнему останавливают сбор.
Это исправляет обработку смены страницы, но не гарантирует устранение исходной сетевой FETCH_ERROR.
Служебные OAuth-запросы, создаваемые самим сайтом, больше не задерживаются очередью каталога:
искусственная задержка может мешать обновлению гостевой сессии. Интервал запросов товаров не уменьшен.
Команды продолжения и имеющиеся CSV/SQLite/JSON остаются совместимыми.

## Исправления

- Исключены формы для льда/выпечки, капучинаторы и явные кухонные принадлежности внутри пищевых разделов.
- Распознаётся «20 пакетиков» и «60 пакетиков». Явный вес/объём из подробностей используется при необходимости. «0,5» без единицы не превращается догадкой в «0,5 л».
- Ошибочные карточки сохраняются отдельно в .issues.jsonl и не прерывают сохранение остальных товаров.
- После каждого раздела сохраняются SQLite и .partial.csv. При ошибке внутри раздела сохраняется уже полученная часть.
- Все успешные ответы API записываются автоматически. Повторный запуск использует их; Firefox открывается только для недостающих запросов.
- Команда recover полностью офлайн и сохраняет исходное время получения цен.
- Удалён повторный промо-раздел детского питания. Сбор начинается после готовности гостевой сессии, без ожидания пустой фоновой очереди сайта. Запросы каталога получают приоритет при сохранении интервала; служебный OAuth сайта не задерживается.

## Восстановить первую зону без сети

Из папки проекта в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m samokat recover --limit 1 --capture-dir .\results\raw_arkhipov --output .\results\samokat_2026-10-21_arkhipov_recovered.csv
```

На предоставленных 75 ответах от 21 октября восстановлены 3232 товара, две карточки вынесены на разбор. Обход занял около 13 секунд, сетевых запросов — 0. Исходные даты цен сохранены.

Карточки на разборе: напиток с записью «0,5» без единицы и пищевой краситель с количеством цветов вместо фасовки. Их исходные данные не потеряны и находятся в .issues.jsonl.

## Продолжить две оставшиеся зоны

```powershell
.\.venv\Scripts\python.exe -m samokat run --limit 3 --output .\results\samokat_2026-10-21_arkhipov_recovered.csv --interval 10 --startup-timeout 600 --capture-dir .\results\raw_arkhipov
```

Первая обработанная зона пропускается. Запрашиваются только недостающие ответы. Для всех зон уберите --limit 3. Для округов есть --okrug ЦАО САО; для отдельных зон — --h3 8711aa632ffffff.

## Файлы и полнота

Для example.csv рядом создаются:

| Файл | Что содержит |
|---|---|
| example.csv | Допустимые товары обработанных зон, ровно 37 колонок |
| example.partial.csv | Товары незавершённой зоны; после её завершения снова может остаться только заголовок |
| example.issues.jsonl | Карточки с ошибками: исходный товар, причина, зона и время |
| example.status.json | Статусы зон и количество товаров/карточек на разбор |
| example.sqlite3 | Контрольные точки, в том числе промежуточный результат |
| example.log | Журнал |
| example.responses/ | Ответы API, если другая папка не задана через --capture-dir |

Статус with_issues означает: обход категорий завершён, но отдельные карточки исключены из основного CSV и сохранены на разбор. Такая зона считается обработанной и не собирается заново при обычном продолжении. В extra её товаров стоят collection_status: complete_with_issues, zone_complete: false и число карточек на разбор. Это не заявление о стопроцентной полноте ассортимента.

Неполные зоны имеют строки только в .partial.csv. Файл с одним заголовком сам по себе не означает отсутствие доставки. Отсутствие доставки записывается специальной строкой лишь после успешного пустого ответа /showcases/list.

Не удаляйте SQLite и папку ответов для продолжения того же прохода. Пока идёт сбор, лучше не открывать основной CSV в Excel: Windows может заблокировать запись. База сохраняется даже при блокировке экспорта; после закрытия файла повторный запуск восстановит CSV.

## Новый временной срез цен

Продолжение намеренно использует записанные ответы и их исходные даты. Для нового среза задайте новое имя CSV и новую папку ответов:

```powershell
.\.venv\Scripts\python.exe -m samokat run --output .\results\samokat_new_snapshot.csv --interval 10
```

Без --capture-dir папка будет samokat_new_snapshot.responses/. Флаг --fresh-requests отключает чтение старых ответов для ещё не обработанных зон; уже завершённые зоны не пересобирает. Для их обновления нужен новый --output.

## Скорость и ограничения

Главное ускорение — не скачивать заново уже полученные категории. На новых складах остаются сетевые запросы: интервал 10 секунд требует не менее 12,5 минуты для 75 запросов, без загрузки сайта и дополнительных запросов. Обещать все 201 зону за два часа нельзя.

По умолчанию интервал — 3 секунды, минимум — 1. В предоставленном запуске с 10 секундами все категории были получены; ранее с более коротким интервалом возникал 403. Поэтому команда продолжения сохраняет 10 секунд. Сокращение паузы может ускорить сбор, но отсутствие блокировок не гарантируется.

При 403, 429 или капче сбор останавливается. Обхода защиты, ротации прокси и автоматических повторов после блокировки нет. Для временных сетевых ошибок и 500/502/503/504 предусмотрено не больше двух повторов.

В обычном сборе для пищевого товара без фасовки может дополнительно запрашиваться подробная карточка. В recover недостающие сведения остаются на разборе, без сети. Режим --details получает подробности всех товаров и существенно медленнее; для него нужен отдельный выходной файл.

Кэш склада учитывает store_id и showcase_id. Доставка определяется по координатам дома address_lat/address_lon, а не центру зоны. При использовании записанных данных время реального наблюдения сохраняется.

## Установка и проверки

В существующем окружении повторная установка не нужна. Для новой распаковки:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m samokat validate .\results\samokat_2026-10-21_arkhipov_recovered.csv
```

Selenium Manager подбирает geckodriver; есть --firefox и --geckodriver для явных путей. Используется временный профиль Firefox без личного аккаунта. Токены и cookie не выгружаются в JSON парсера.

Адаптер рассчитан на публичный web-клиент Самоката 2.86.1. При изменении версии/схемы потребуется обновление. Атрибуция OpenStreetMap сохранена в data/README_task.md и data/map.html.
