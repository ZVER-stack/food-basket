# Ночное автопродолжение Самоката

Контроллер установлен в `C:\Users\andre\OneDrive\Desktop\samokat_parser\samokat_autoresume.py`.
Параметр контроллера `--immediate-retry` убирает паузы между проходами после
подтверждённых ошибок, включая HTTP 403. HTTP 429 сохраняет задержку.
После трёх неудачных повторов без прогресса контроллер останавливается.
Он ждёт фактического завершения процесса; инициализация Firefox и чтение
сохранённых ответов при каждом новом запуске по-прежнему занимают время.
Без этого параметра используется описанная ниже схема пауз.
При временной блокировке Windows во время атомарной замены служебного файла
состояния запись повторяется до двух секунд. Если доступ не восстановился,
контроллер останавливается; ошибки сохранения результатов по-прежнему требуют проверки.
Он запускает из этой папки исходную команду:

```powershell
.\.venv\Scripts\python.exe -m samokat run --output .\results\samokat_2026-10-21_arkhipov_recovered.csv --interval 10 --startup-timeout 600 --capture-dir .\results\raw_arkhipov
```

Перезапуски идут в фоне. Исходное окно PowerShell не используется для ввода.
Текущий CSV, SQLite, сохранённые ответы и механизм продолжения остаются теми же.
Первый уже идущий процесс оставлен работать: контроллер наблюдает его завершение
и только читает окончание вывода исходной консоли. Нажатий клавиш не выполняет.
После новой подтверждённой ошибки прохода и выхода процесса с кодом 2 управление перейдёт
к фоновым запускам. Закрывать исходное окно до этого перехода не следует.

После ошибки (HTTP 403, FETCH_ERROR, тайм-аут Firefox и другие) и сообщения
«Проход не завершён» контроллер ждёт 15 минут. Если повторные попытки не дают
прогресса, пауза увеличивается до 30 и 60 минут. После трёх повторных неудач
без прогресса контроллер останавливается. При прогрессе пауза возвращается к 15 минутам. Интервал
собственных запросов каталога — 10 секунд. Обхода блокировок и капчи нет.
Капча, ошибки доступа к файлам или базе и ручное прерывание останавливают
автоповторы. Неоднозначное завершение без подтверждения ошибки также требует
проверки. Прогрессом считаются завершённые зоны и рост количества товаров
в текущей зоне; одни лишь новые сырые ответы не сбрасывают счётчик. Проверяется отсутствие другого
запущенного парсера; второй контроллер блокируется отдельным файлом-замком.

После обработки всех 201 зон контроллер заканчивает работу. На время работы
он временно предотвращает автоматический сон Windows, не меняя план питания;
экран может погаснуть и заблокироваться. Выключение компьютера, закрытие крышки
ноутбука и ручной перевод в сон всё равно прервут выполнение.

Проверить состояние из папки проекта:

```powershell
.\.venv\Scripts\python.exe .\samokat_autoresume.py --status
```

Отключить последующие автозапуски:

```powershell
.\.venv\Scripts\python.exe .\samokat_autoresume.py --stop
```

Эта команда не обрывает уже идущий проход: он завершится, но новых повторов не будет.
Не запускайте параллельно дополнительный экземпляр вручную.
