# Парсинг цен: Лавка, Самокат, ВкусВилл, Ozon fresh

| Файл | Что это |
|---|---|
| `hexagons.csv` | 201 зона внутри МКАД: для каждой — адрес дома, куда ставить доставку |
| `map.html` | карта зон — открыть в браузере |
| `template.csv` | шаблон: в каком виде сохранять данные |
| `example.csv` | тот же шаблон с заполненными строками-примерами |

## Зоны

Москва внутри МКАД разбита на **201 шестиугольник** ([H3](https://h3geo.org/), разрешение 7).
Каждый примерно 4,8 км², центры соседних — в 2,3 км друг от друга.

`hexagons.csv`:

| Колонка | Что это |
|---|---|
| `h3_index` | ID зоны — его пишем в данные |
| `lat`, `lon` | центр зоны |
| `address` | **адрес доставки** — жилой дом, ближайший к центру зоны: `Москва, Бакунинская улица, 60/2` |
| `address_lat`, `address_lon` | координаты этого дома — если сервис принимает координаты, а не текст |
| `address_dist_m` | сколько метров от центра зоны до дома |
| `address_in_zone` | `True` — дом внутри зоны. `False` у 4 лесопарковых зон Лосиного Острова: в них нет домов, взят ближайший снаружи |
| `okrug`, `district` | округ и район — чтобы делить работу и смотреть результат |

Для каждой зоны: ставим адрес доставки на дом из `address` → снимаем каталог → пишем строки в CSV.
Если в зоне не нашлось жилого дома, взято ближайшее здание с адресом в ней. Если сервис не
принимает адрес, сдвиньтесь к соседнему дому той же улицы: главное — остаться в своей зоне.

## Что собрать

Одна строка = один товар в одной зоне. Колонки — как в `template.csv`, их 37.
**Обязательных — 8** (отмечены ✱), остальные заполняйте, если сервис это показывает.
Пустая колонка — нормально.

**Где и когда**

| Колонка | Что писать |
|---|---|
| `service` ✱ | `lavka`, `samokat`, `vkusvill` или `ozon_fresh` |
| `h3_index` ✱ | ID зоны из `hexagons.csv` |
| `parsed_at` ✱ | когда сняли товар, московское время: `2026-10-15 20:15:03` |
| `store_id` | ID даркстора или склада, если сервис его показывает |

**Доставка в зону** (одинаковая для всех товаров зоны)

| Колонка | Что писать |
|---|---|
| `delivery_eta_min` | обещанное время доставки, минут: `15` |
| `delivery_fee` | стоимость доставки, ₽ |
| `min_order` | минимальная сумма заказа, ₽ |

**Товар**

| Колонка | Что писать |
|---|---|
| `product_id` ✱ | ID товара в сервисе (из API или ссылки на товар) |
| `name` ✱ | название как на сайте |
| `brand` | бренд |
| `manufacturer` | производитель |
| `country` | страна производства |
| `category` | категория, уровни через « > »: `Молочное > Молоко` |

**Цена**

| Колонка | Что писать |
|---|---|
| `price` ✱ | цена, которую платим сейчас (со скидкой), ₽ |
| `price_regular` ✱ | цена без скидки (зачёркнутая), ₽. Скидки нет — то же, что `price` |
| `price_card` | цена по карте лояльности или подписке, если показана отдельно |
| `discount_percent` | скидка в %, если сайт её показывает: `20` |
| `promo` | текст акции: `2 по цене 1`, `-20% по карте` |
| `unit_price` | цена за единицу, если сайт её показывает: `331.67` |
| `unit_price_basis` | за что эта цена: `1 кг`, `1 л`, `1 шт` |

**Количество и наличие**

| Колонка | Что писать |
|---|---|
| `amount` ✱ | граммовка или штуки как на сайте: `500 г`, `1 л`, `10 шт`, `6 шт × 100 г` |
| `in_stock` | есть в наличии: `true` / `false` |
| `stock_qty` | сколько осталось, если сайт показывает («осталось 3 шт» → `3`) |

**Состав, КБЖУ, отзывы**

| Колонка | Что писать |
|---|---|
| `kcal`, `protein`, `fat`, `carbs` | калории, белки, жиры, углеводы на 100 г |
| `composition` | состав |
| `description` | описание |
| `shelf_life` | срок годности как на сайте: `6 мес`, `21 сут` |
| `storage_conditions` | условия хранения |
| `rating` | рейтинг: `4.8` |
| `reviews_count` | число отзывов или оценок |
| `labels` | бейджи и метки через `;`: `Новинка; Без лактозы` |

**Ссылки и всё остальное**

| Колонка | Что писать |
|---|---|
| `image_url` | ссылка на картинку |
| `url` | ссылка на товар |
| `extra` | **всё, для чего нет колонки**, в виде JSON: `{"position": 2, "barcode": "4601234567890"}` |

Нашли интересное поле, которого нет в таблице, — кладите его в `extra`. Заготовка кода ниже делает
это сама: всё, что `get_catalog` вернёт сверх колонок шаблона, попадёт в `extra`. Колонки шаблона
не переименовываем. Если всё же добавили свою колонку, она не потеряется: при склейке её
содержимое тоже переедет в `extra`.

**Правила:**
* цены и числа — через точку: `89` или `89.9`, без «₽» и «%»;
* сервис в зону не доставляет — одна строка с `service`, `h3_index`, `parsed_at`, остальное пусто
  (см. последнюю строку `example.csv`).

## Как сохранить

Один CSV на сервис за один проход: **`<сервис>_<дата>_<фамилия>.csv`**, например
`lavka_2026-10-15_ivanov.csv`. Кодировка UTF-8, разделитель — запятая. Готовый файл — в общую
папку [ссылка].

## Заготовка кода

Осталось написать `get_catalog(address, lat, lon)`: поставить адрес доставки (текстом или
координатами — как удобнее сервису) и вернуть товары списком словарей с колонками из таблицы выше.
Нужные запросы ищите в браузере: DevTools → Network.

```python
import json
import os
import time
from datetime import datetime

import pandas as pd

SERVICE = "lavka"
OUT = f"{SERVICE}_{datetime.now():%Y-%m-%d}_ivanov.csv"
COLUMNS = list(pd.read_csv("template.csv").columns)


def get_catalog(address, lat, lon):
    """Вернуть [] если сервис сюда не доставляет, иначе список товаров:
    [{"product_id": "…", "name": "…", "price": 89, "price_regular": 109, "amount": "950 мл", …}, …]
    Можно возвращать любые поля: чего нет в шаблоне, уйдёт в extra."""
    raise NotImplementedError


def to_row(product, zone, now):
    row = {k: v for k, v in product.items() if k in COLUMNS}
    rest = {k: v for k, v in product.items() if k not in COLUMNS}
    if rest:
        row["extra"] = json.dumps(rest, ensure_ascii=False, default=str)
    row.update(service=SERVICE, h3_index=zone.h3_index, parsed_at=now)
    return row


zones = pd.read_csv("hexagons.csv")
for i, zone in enumerate(zones.itertuples(), start=1):
    now = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    products = get_catalog(zone.address, zone.address_lat, zone.address_lon)
    rows = [to_row(p, zone, now) for p in products]
    if not rows:  # нет доставки
        rows = [{"service": SERVICE, "h3_index": zone.h3_index, "parsed_at": now}]
    # дописываем после каждой зоны: если скрипт упадёт, собранное не пропадёт
    pd.DataFrame(rows, columns=COLUMNS).to_csv(OUT, mode="a", header=not os.path.exists(OUT), index=False)
    print(f"[{i}/{len(zones)}] {zone.h3_index}: {len(products)} товаров")
    time.sleep(1)
```

## Сколько времени

Полный проход по 201 зоне должен укладываться примерно в **2 часа**, это ~35 секунд на зону.
* Сначала отладьтесь на 3–5 зонах: `zones.head(5)`.
* Если каталог долгий, а сервис показывает ID даркстора, снимайте каталог один раз на даркстор:
  соседние зоны часто обслуживает один и тот же. Сохраните товары, а для следующих зон с тем же
  `store_id` просто повторите их с новым `h3_index`.
* Вдвоём на одном сервисе — делите зоны по округам: `zones[zones.okrug.isin(["ЦАО", "САО"])]`.

## Правила аккуратного парсинга

* Только публичная витрина, без входа в личные аккаунты.
* Не чаще одного запроса в секунду.
* Получили 429, 403 или капчу — остановитесь и увеличьте паузу. Защиту сервисов не обходим.
