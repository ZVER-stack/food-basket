# Данные Ozon Fresh — КП2

Данные размещаются во [выпуске ozon-fresh-kp2-2026-11-10](https://github.com/ZVER-stack/food-basket/releases/tag/ozon-fresh-kp2-2026-11-10) отдельно от Git-истории исходников.

| Архив | Содержимое |
|---|---|
| `snapshot.sqlite.gz` | Согласованная резервная копия основной базы текущего снимка |
| `ozon_fresh.csv.gz` | Полная архивная таблица парсера |
| `ozon_by_house.csv.gz` | Итоговая таблица по адресам: 992 534 строки, 13 148 SKU, 13 колонок |
| `product_metadata_backfill.sqlite.gz` | Проверенные статические характеристики товаров и спорные записи |
| `checksums.json` | Размеры и SHA-256 сжатых и распакованных файлов; результат SQLite quick_check |

Для использования распакуйте `.gz` любым архиватором с поддержкой gzip. Каждая SQLite проходит `PRAGMA quick_check` перед упаковкой. Рабочие базы при этом не меняются.

Это промежуточный результат: 159 из 197 адресов обработаны, 29 без пропусков по проверкам парсера; 160-й адрес частично собран. Данные накоплены в разные дни начиная с 18 октября 2026 года. База, полный CSV и компактный CSV имеют разные назначения и не обязаны содержать одинаковое число строк: компактная таблица включает сохранённые наблюдения частичного дома.

Отсутствующие характеристики остаются неизвестными. Цены берутся из одного сохранённого наблюдения конкретного адреса; статические характеристики сопоставляются по SKU, названию и фасовке. Полное покрытие ассортимента и одновременная актуальность всех цен не подтверждены.
