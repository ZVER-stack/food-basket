# Самостоятельный запуск Ozon Fresh в PowerShell

Код обновлён 27 октября. Установка не запускает сбор. Настроены 7 общих сборщиков и интервал на каждый сборщик: **1,1 → 2,1 → 3,1 → … → 14,1 → 15 секунд**. Первое новое ограничение HTTP 403 или 429 повышает интервал до 2,1 секунды, следующий эпизод — до 3,1 и далее по 1 секунде до максимума 15. Одновременные ошибки читателей в пределах общей паузы считаются одним эпизодом. Достигнутая ступень сохраняется при перезапуске; автоматического уменьшения нет.

При первом запуске новой политики прежний фиксированный интервал 5 секунд заменяется начальным 1,1. Сохранённое ожидание доступа и необходимость ручной проверки сохраняются. Если сервер явно прислал `Retry-After`, указанное им время может превышать 15 секунд. Ожидание ручной капчи также не ограничивается пятнадцатью секундами.

## 1. Открыть Chrome

Запуск настроен без прокси. Закройте только прежнее окно Chrome парсера, чтобы убрать параметры предыдущего запуска через Happ, и выполните:

```powershell
Set-Location "C:\Users\maxik\PycharmProjects\PythonProject\fresh_fast"
.\01_open_old_chrome.cmd
```

Файл открывает прежний профиль `C:\ozon_chrome` с параметром `--no-proxy-server`. Дождитесь товара и цен, при необходимости пройдите капчу вручную. Когда PowerShell показывает `Press any key to continue`, нажмите любую клавишу, чтобы вернуться к приглашению `PS ...>`.

Этот параметр отключает прокси Chrome. Для подключения также без VPN отключите соединение Happ: работающий режим VPN/TUN может направлять трафик через VPN независимо от настроек браузера.

## 2. Продолжить сохранённый сбор

В том же PowerShell:

```powershell
.\08_continue_all.cmd
```

Это основной сбор всех 197 адресов. Он продолжит сохранённый снимок с незавершённого адреса; уже обработанные адреса того же снимка повторно не собираются. На момент последней остановки обработано 18 адресов, 19-й сохранён частично. Сам файл 08 не открывает Chrome.

Оставьте компьютер включённым, Chrome и окно сборщика открытыми. Чат можно закрыть: Python работает самостоятельно. Не запускайте второй сборщик и не меняйте адрес доставки вручную.

## 3. Смотреть прогресс

В **новом** окне PowerShell:

```powershell
Set-Location "C:\Users\maxik\PycharmProjects\PythonProject\fresh_fast"
.\13_watch_captcha.cmd
```

Монитор проверяет локальные файлы каждые 5 секунд, показывает прогресс, ожидание доступа, запрос ручной проверки и завершение. В нём нет запросов к Ozon. Пока сбор остановлен, в статусе могут отображаться 5 секунд последнего запуска и отдельно новая настройка следующего запуска.

Разовая проверка в свободном окне PowerShell:

```powershell
Set-Location "C:\Users\maxik\PycharmProjects\PythonProject\fresh_fast"
.\12_status.cmd
```

## 4. Если нужна капча или ручная проверка доступа

Откройте в том же Chrome карточку, запущенную файлом 01. Пройдите капчу вручную, если она показана, и убедитесь, что товар и цены видны. Затем в **свободном** окне PowerShell выполните:

```powershell
Set-Location "C:\Users\maxik\PycharmProjects\PythonProject\fresh_fast"
.\06_resume_after_captcha.cmd
```

Файл 06 передаст подтверждение ожидающему процессу. Второй файл 08 при этом запускать не нужно. Пока требуется ручное подтверждение, запросов к Ozon нет. Сообщение об обычной паузе после 403/429 само по себе не означает наличие капчи.

## 5. Остановить и продолжить позже

В основном окне сборщика нажмите **Ctrl+C** один раз и дождитесь сохранения результата. Если появится `Terminate batch job (Y/N)?`, введите **Y** и нажмите Enter. Для продолжения позже снова используйте файл 08.

Ctrl+C в окне монитора закрывает только монитор и не останавливает сбор.

## Результаты

Путь к результатам показывает файл 12. Текущий снимок:

`C:\Users\maxik\PycharmProjects\PythonProject\fresh_fast\results\full_shared_20261018_111443`

- `ozon_fresh.csv` — 37 колонок с `product_id`, строки адресов с завершённым обходом.
