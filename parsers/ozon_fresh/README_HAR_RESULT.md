# Результат обработки вашего HAR

HAR `PythonProject\ozon_fresh.har` обработан локально. Входа в аккаунт в нём не
обнаружено. Исходный HAR не изменён и в архив результата не включён.

Это **частичная запись**, а не завершённый сбор Москвы. Сведения о ценах относятся
к моменту записи 17 октября 2026 года; `parsed_at` взят из HAR и приведён к Москве.

**Файлы данных:**

- `captured_partial.csv` — 138 реальных строк с известной обычной ценой и
  упаковкой; ровно 37 колонок исходного шаблона. Это частичные наблюдения из
  записанной подборки, её принадлежность ко всем необходимым категориям не проверена.
- `incomplete_observations.csv` — ещё 70 строк: у них обычная текущая цена
  отсутствует, показана только цена по Ozon Банку. Поле `price_card` сохранено,
  обязательное `price` оставлено пустым. Этот файл **не является итоговым CSV**.
- `capture_report.json` — подтверждения адресов, номера страниц, ограничения и
  следы обработки. Во всех отчётах полнота обозначена `false`.
- `food_categories.json` — 80 маршрутов категорий из реального меню Fresh:
  продукты и детское питание, без одежды, электроники, косметики и зоотоваров.
  Категории выбираются по ветке меню, а не совпадению слов в названии товара.
  Родительские маршруты с известными дочерними маршрутами не дублируются.
- `household_category_candidates.json` — наблюдавшаяся ветка «Бытовая химия и
  хозтовары». Она шире химии и требует уточнения подкатегорий перед полным сбором.
- `testdata/public_tiles.json` — три небольших настоящих примера карточек, с
  удалёнными блоками отслеживания и query-параметрами ссылок. Полный HAR сюда не попал.

## Что выяснилось

1. Адрес действительно сохраняется. В HTML основной страницы есть выбранный дом;
   по этому заголовку привязаны товары. Промежуточный API-ответ с «Уточнить адрес»
   отдельно исключён. Данные не копировались на другие зоны.
2. Товары находятся в `tileGridDesktop-…`. Порядок элементов `mainState` не
   гарантирован, поэтому цена и имя определяются по их типу и роли.
3. `priceV2.priceStyle.styleType=CARD_PRICE` обозначает цену по карте. Она не
   заменяет обычную цену. `ACTUAL_PRICE` и `SALE_PRICE` обрабатываются отдельно.
4. Кнопка с `freshAddToCart` подтверждает принадлежность предложения к Fresh.
   Поле `selectedDeliverySchema=131` — схема доставки, **не ID склада**.
   `quantityButton.maxItems` не выдаётся за остаток на складе.
5. Первая страница хранит следующую ссылку в `infiniteVirtualPaginator`,
   последующие — в корневом `nextPage`. Обработаны обе формы.
6. У каждого адреса записаны страницы 1–13. Последняя записанная страница ссылается
   на 14-ю, поэтому конец каталога не достигнут.
7. Записана подборка «Продукты от Ozon fresh». Полнота всех продуктов и бытовой
   химии этим не подтверждается. Публичного ID склада в исследованных виджетах
   не обнаружено, поэтому кеширование между адресами автоматически не включается.

## Код и проверки

`ozon_har_catalog.py` разбирает настоящий формат Ozon и повторно обрабатывает HAR
без сетевых запросов. `ozon_fresh_fast.py` поддерживает этот декодер через
`card_decoder="ozon_tile_v2"`, а также обе формы пагинации. При отсутствии ID
склада он оставляется пустым, повторное использование между зонами отключается.
Цена по карте без обычной цены вызывает остановку полного прохода, а не подмену.

Проверки выполняются из `PythonProject\fresh_fast`:

```powershell
..\.venv\Scripts\python.exe -m unittest discover -s . -p "test_ozon*.py" -v
```

Повторная обработка записи:

```powershell
..\.venv\Scripts\python.exe .\ozon_har_catalog.py --har ..\ozon_fresh.har --zones .\hexagons.csv --out-dir .\results\capture
```

Тесты проверяют логику и три настоящих примера карточек. Они не подтверждают
возможность живого сетевого прохода по 197 зонам.

## Доступ к работающему браузеру

После изучения HAR контрольный прямой запрос снова получил редирект 307 и был
остановлен. Запуск отдельного Chrome с локальным отладочным подключением
автоматическая проверка среды отклонила: требуемое разрешение на запуск процесса
здесь недоступно. Пробовать другие способы обхода этого запрета агент не стал.

Для продолжения пользователь может вручную запустить файл
`PythonProject\fresh_fast\start_chrome_for_parser.cmd`. Он открывает установленный
Chrome с **отдельным пустым профилем** и локальным отладочным портом `127.0.0.1:9223`.
Личный профиль не используется. В открывшемся окне нужно открыть Fresh без входа
в аккаунт, дождаться каталога и сообщить, что окно готово. Сам запуск и успешная
загрузка ещё не означают, что сайт разрешит весь сбор; при защите сбор остановится.

После подключения остаётся проверить адресный протокол вживую, уточнить бытовую
химию, получение обычных цен для `CARD_PRICE`, а затем замерить 3–5 зон. Лимит
в два часа **пока не подтверждён**. Конфигурация `contract.unconfigured.json`
остаётся выключенной: HAR не превращает непроверенный живой контракт в рабочий.
