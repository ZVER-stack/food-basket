# Бесплатная оптимизация повторного полного прохода

Первичный процесс остановлен по указанию пользователя. Установка этого кода
его не возобновляет. Полного сбора197адресов за2часа пока нет.

Добавлен справочник между проходами. Новый полный снимок может брать проверенные
SKU из уже завершённых адресов прежнего снимка, даже если прежний снимок не
успел обойти все197адресов. Уже обойдённых четырёх адресов достаточно для
справочника; заново строить его с нуля не требуется. Исходная база читается
без изменения. Незавершённые адреса и сырые частичные страницы в справочник
подтверждённых цен не попадают.

В новом полном проходе страницы категорий каждого адреса по-прежнему читаются.
При совпадении SKU, названия, фасовки, наличия, основания цены и всех видимых цен
обычная цена может браться из справочника. Это ранее разрешённое пользователем
предположение, а не новая проверка обычной цены. Даже на том же адресе она имеет
`ordinary_price_inferred=true`, `ordinary_price_verified_for_address=false`
и `ordinary_price_origin.snapshot_id` с исходным источником и временем.
Новая или изменившаяся выдача требует карточки, если обычной цены/фасовки нет.
Исторические цены без отметки проверки и уже перенесённые цены не становятся
новыми подтверждёнными источниками. Отсутствующие в текущем полном каталоге SKU
не копируются из справочника в результат.

При создании нового полного снимка через run_parser.py прежний активный снимок
автоматически выбирается справочником. При продолжении того же снимка повторного
импорта нет. Явный источник задаётся `--reference-snapshot ПУТЬ_К_ПАПКЕ_СНИМКА`.
Список категорий и зон должен совпадать; проверяется fingerprint.
Режим `--price-policy verified_each_address` перенос обычных цен запрещает.
37 колонок,8 обязательных полей, проверки SKU/Fresh/адреса сохранены.

Добавлен `10_full_two_hours.cmd`: полный обход с общим бюджетом7200секунд,
четыре общих читателя категорий и карточек. Паузы403/429 и ручная капча входят
в бюджет; последняя минута зарезервирована для завершения запросов и экспорта.
Истечение бюджета прекращает и ожидание ручного доступа. Обёртка не запускает
его заново после истечения срока. CAPTCHA при первичной проверке доступа
прерывает ограниченный запуск без запросов к Ozon. Число законченных адресов
и фактическое время сохраняются в отчёте; неполный проход имеет complete=false.

**Файл10 не является гарантией, что все197адресов успеют закончиться.**
Проверка времени в живом полном проходе ещё не выполнена. Ветка08 с явным
`--continue-until-finished` сохраняет прежнее поведение без двухчасового срока.
Файл09 остаётся отдельным выборочным режимом и полным обходом не считается.

Замер без сетевых запросов на сохранённых ответах первого адреса:

- 2402SKU в подвыборке с сохранёнными исходными котировками каталога;
- расчётные запросы карточек:1431 без прежнего справочника,246 со справочником;
- 1185 запросов карточек исключены из плана этой подвыборки;
- 4513старых наблюдений без исходной сигнатуры исключены из обеих частей сравнения;
- 902страницы каталога не сокращены.

Это воспроизведение старых ответов при предположении неизменности видимых цен.
Оно не подтверждает скорость живого сбора и точность перенесённой обычной цены
сейчас. Полные числа — optimization_benchmark.json. Локальные тесты проверяют
перенос происхождения цены, строгий режим, изменившиеся цены, неполные источники,
запрет ложного подтверждения цены и остановку по исходному сроку.
